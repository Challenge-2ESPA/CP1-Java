# Exercícios de Java

## Sobre o projeto

Este projeto foi desenvolvido como parte da atividade Checkpoint, com o
objetivo de aplicar os conceitos iniciais de desenvolvimento em Java.

A atividade é composta por 15 exercícios, desenvolvidos com foco na
prática dos principais tipos de instruções, estruturas de controle e
paradigmas da linguagem Java, explorando conceitos de programação
procedural, funcional e orientada a objetos.

## Tecnologias utilizadas

-   Java
-   JDK
-   IntelliJ IDEA
-   Git e GitHub para versionamento e organização do projeto

## Como executar

É necessário ter o JDK instalado na máquina.

Para verificar a instalação, utilize:

``` bash
java -version
```

O projeto deve ser aberto no IntelliJ IDEA. Após abrir o projeto, basta
selecionar o exercício desejado e executar a classe Java correspondente.
